# 微云 · 逐项分享

个人使用的 Manifest V3 Chrome extension，版本 `0.1.0`（测试版）。

打开微云网页版的一个目录，点击一次，即可完整读取目录、逐项生成带密码的独立分享，并按数字自然顺序导出 TXT。

**当前验证边界：核心逻辑和本地模拟页面测试；真实微云当前登录页面的自动化连接持续超时，尚未完成真实网站端到端验收。请先在专用的小测试目录试用，再操作正式文件。** 网站更新、菜单事件或保存行为不一致时，插件会停止并提示，不会把未验证结果标为完成。

## 安装

1. 解压发布的插件 ZIP；或直接使用交付的 `weiyun-batch-share` 目录。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择**直接包含 `manifest.json` 的插件目录**，不要选择 ZIP 文件。
5. 在 Chrome 工具栏的扩展程序菜单中固定“微云 · 逐项分享”。
6. 在同一个 Chrome profile 中登录 `https://www.weiyun.com`。Codex 内置浏览器与 Chrome 的登录状态不能假定会共享。

插件不需要 Node.js、Python、AI API key 或后端服务。Node.js 仅在重新构建源码时使用。

## 开始使用

1. 进入 `https://www.weiyun.com/disk/folder/...` 对应的微云目录，等页面显示总项数。
2. 点击浏览器工具栏中的插件图标，打开 Side Panel。
3. 确认面板显示的是目标目录及正确数量。
4. 点击“全部分享并导出 TXT”。这一步将为该目录快照中的每个直接项目创建或复用独立分享。
5. 保持目标 tab 打开；不要同时在该 tab 手动选择项目、导航目录或操作弹窗。
6. 完成后 TXT 自动下载到 Chrome 的下载位置。中途也可点击“导出 TXT”取得部分结果。

默认范围是当前目录的直接项目。分享一个文件夹本身，不递归为其内部文件另建链接。已有密码保留，新链接使用微云自动生成的密码；有效期不主动更改，以页面实际设置为准。

## 暂停、恢复与核对

- **暂停**：当前项目的加密码、验证及保存结束后生效；目录采集阶段可直接暂停。
- **继续任务**：读取原快照，跳过该任务中已经验证完成的项目，优先处理上次中断的项目。
- **仅重试失败项**：只对确认未造成不确定外部变更的失败项重试；不自动重试“需核对”项。
- **核对当前项目**：结果不确定时，在微云中打开准确项目的分享弹窗，处理列出的相关链接，勾选说明后继续。
- **跨页面恢复**：刷新、关闭浏览器、重启后需重新打开原目录并点击插件图标。不能识别稳定账号标识时，必须手动确认原账号。
- **原执行器失联**：不能确认它已经停止时，先刷新或关闭原 tab，再回原目录恢复，避免两个 runner 同时操作。

微云现有 UI 是先生成链接、再添加密码，存在短暂的无密码窗口。插件不保证创建的第一瞬间就有密码。密码无法确认保存时整批停止，优先提示处理当前链接。

本插件不提供取消历史分享、删除微云文件、绕过验证码或绕过限流的功能。

## 导出与隐私

- TXT：UTF-8 BOM、Windows CRLF，按序记录名称、链接、密码、可读取的有效期和验证时间。
- 进度备份：JSON，含分享链接和密码，供故障恢复或迁移使用，请妥善保存。
- 页面诊断：只输出 allowlist 内的 DOM 结构信息，不输出文本、文件名、分享 URL、密码、cookie 或 token。
- 数据只保存于 extension 的本机 `chrome.storage.local`，不使用 `storage.sync`，不连接远程服务器。
- 本地保存不是加密保险箱。其他能读取该 Chrome profile 的软件可能访问数据；导出文件也应妥善保管。
- 删除本地进度只移除 extension 中的任务记录，不会取消微云已有分享。

申请权限为 `activeTab`、`scripting`、`storage`、`sidePanel`、`downloads`；不申请全站访问、cookie、clipboard、debugger 或 nativeMessaging 权限。

## 常见问题

**面板提示没有访问权限**

回到目标微云 tab，点击浏览器工具栏中的插件图标。浏览器右侧菜单中打开面板不一定会授予 `activeTab`。

**页面显示 60 项，但只读取到 50 项**

插件会尝试滚动或已识别的分页入口；数量不能核对时停止，不会只分享前 50 项。可在面板导出页面诊断，用于更新 DOM adapter。

**添加密码后停在“需核对”**

不能确认密码已经保存、重开弹窗出现新链接、链接与历史记录不同等情况均会暂停。请查看该项提示及所有相关链接，不要重复点击“重新建立任务”。

**为什么不并发操作**

网页只有一个分享弹窗。首版通过一次 content script 完成批量流程、条件等待和直接读取弹窗提速，分享动作保持串行。尚未接入或验证微云私有 API。

**多久能完成 60 项**

本地 fixture 不代表微云服务端速度。真实耗时受网站响应、密码保存、账号限流影响，应先在测试目录实测，不能承诺固定秒数。

**下载没有弹出保存位置**

默认使用 Chrome 的下载位置。若浏览器配置为每次询问，会要求选择保存位置。下载失败可重新导出，不需要重新分享。

**支持其他浏览器吗**

目标平台是 Chrome 120+；本次隔离测试使用 Chromium 系浏览器。未承诺 Firefox、Safari、Codex 内置浏览器或所有 Edge 功能兼容。

## 从源码构建

源码包包含 `src/`、`public/`、`scripts/`、`tests/`，不包含用户分享记录及构建依赖。

需要 Node.js 22+：

```powershell
npm install
npm run typecheck
npm test
npm run build
```

将生成的 `dist` 目录加载为 unpacked extension。修改源码后，重新构建，在扩展管理页点击“重新加载”，再刷新微云页面。更新前先暂停任务并备份进度，不要在运行过程中重载 extension。

浏览器 integration tests 使用 Playwright、独立 profile 与完全拦截的本地微云 fixture，不访问真实微云服务，不使用用户 Chrome profile：

```powershell
npm install --no-save playwright
npx playwright install chromium
$env:WEIYUN_CHROME_PATH = '<支持 --load-extension 的 Chromium 或 Chrome for Testing 可执行文件路径>'
node scripts/browser-test.mjs
```

正式 Chrome 新版本可能禁用用于 automation 的 `--load-extension` flag；这是测试启动方式限制，不代表用户通过扩展管理页手动加载 unpacked extension 不可用。

## 源码结构

| 模块 | 用途 |
| --- | --- |
| `src/adapter.ts` | 微云 DOM selectors、目录完整采集、项目定位、菜单/弹窗/密码状态读取 |
| `src/runner.ts` | 串行状态机、中断恢复顺序、重开验证、暂停边界 |
| `src/model.ts` | 类型、状态转换、URL/账号/结果校验 |
| `src/background.ts` | 消息校验、单 runner、任务保存、导出、恢复入口 |
| `src/store.ts` | 串行化写入，等待持久化 ACK |
| `src/importer.ts` | 旧 checkpoint 与插件备份的候选数据导入 |
| `src/panel.ts` | Side Panel、进度、核对、导入/导出操作 |
| `tests/core.test.ts` | 状态机与异常恢复 regression tests |
| `tests/fixture.html` | 无需登录、不会真实分享的测试页面 |

待完成的真实网站验收：事件触发、当前 DOM selectors、稳定项目身份、同一分享的复用语义、服务端保存后的密码保留、限流/验证码提示，以及安装后的 toolbar action → Side Panel 链路。
